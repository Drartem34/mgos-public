# kioskOS — Graphite Theme & Nautilus Modernization Package

Цей пакет містить оптимізовану тему **«Графіт» (Graphite)** та конфігурацію продуктивності для файлового менеджера Nautilus (GNOME Files) та середовища Hyprland (kioskOS).

## Вміст пакунку (`~/.config/hyprland/kiosk/`)

1. **`graphite.css`** — Авторська тема в глибоких графітових тонах (Matte Graphite Slate: `#141619`, `#17191d`, `#101214`) для Libadwaita та GTK4.
   - Повністю вичищено важкі CSS-анімації та радіальні ріпли Materia.
   - Миттєвий відгук елементів (мікро-переходи 70–90 мс).
   - Елегантна капсула статусу (`floating-bar`), акуратний сайдбар та плавні скролбари.
2. **`gtk.css` & `gtk-dark.css`** — Симлінки на `graphite.css` для GTK4.
3. **`gtk-3.0.css`** — Гармонійна супутня гранітно-графітова тема для вікон вибору файлів GTK3.
4. **`settings.ini`** — Налаштування GTK (темний режим, іконки MacTahoe, шрифт SF Compact, курсор Bibata).
5. **`apply-theme.sh`** — Скрипт миттєвого розгортання теми та системних GSettings ключів.
6. **`clean-cache.sh`** — Скрипт оптимізації дискового простору та очищення застарілих мініатюр.

## Оптимізації швидкодії та стабільності

- **Усунення вильотів (Crash Fix):** Встановлено `GSK_RENDERER=ngl` (Next-Gen OpenGL) замість нестабільного рушія Vulkan на графіці Intel Iris Xe (Raptor Lake), що ліквідувало аварійні збої ядра `SIGSEGV` у `libvulkan_intel.so`.
- **Ліквідація зависань (Zero Freezes):**
  - Замасковано зламані юніти `localsearch-3.service` (D-Bus таймаути 25–30 с зникли).
  - Вимкнено повнотекстовий індексатор `fts-enabled false` та підрахунок розмірів каталогів `show-directory-item-counts 'never'`.
- **Моментальний Google Drive (rclone):**
  - Переведено на повне локальне VFS-кешування (`--vfs-cache-mode full`).
  - Кешування структури директорій (`--dir-cache-time 1000h`) та атрибутів файлів (`--attr-timeout 1000h`).
  - Автоматичне сповіщення про зміни з хмари кожні 15 секунд (`--poll-interval 15s`).
  - Фоновий розігрів дерева папок (`find -maxdepth 2`) при монтуванні — швидкість відкриття скоротилася з 35 секунд до 5–14 мілісекунд!
