# Mg Share для Windows

Той самий Mg Share, що в mgOS, тільки для Windows: файли й посилання між ПК і телефоном через Wi-Fi (застосунок Mg Share на Android).

**Завантажити:** сторінка релізу `mgshare-windows` у цьому репо → `MgShare.exe` (збирається автоматично GitHub Actions).

## Як користуватись

| Що зробити | Як |
|---|---|
| **Перший раз: з'єднати телефон** | клік по зеленій іконці в треї → «Додати» → на телефоні Mg Share → «Додати пристрій» → наведіть камеру на QR |
| **ПК → телефон** | перетягніть файл на **зелену смужку вгорі по центру екрана** → вона розкриється «Відпустіть — на телефон» → відпустіть → натисніть свій телефон. Якщо телефон один — файл піде одразу |
| | або ПКМ по файлу в Провіднику → **Надіслати → Mg Share** |
| | або клік по телефону в попапі → вибрати файл |
| **Посилання/текст ПК → телефон** | ПКМ по телефону в попапі → «Надіслати текст / посилання з буфера» |
| **Телефон → ПК** | на телефоні «Поділитися» → Mg Share. Файли падають у `Завантаження\Mg Share`, сповіщення в куті — клік відкриває |
| **Посилання телефон → ПК** | «Поділитися» посиланням → Mg Share; клік по сповіщенню відкриває його в браузері |

Меню іконки в треї (ПКМ): отримані файли, увімкнути/вимкнути смужку вгорі, автозапуск із Windows, вийти.

## Вимоги
- ПК і телефон в одній Wi-Fi мережі; у Windows ця мережа — «Приватна».
- Брандмауер: при першому запуску дозволити Mg Share (порт 47811 TCP+UDP).

## Як влаштовано
- `mgshare_win.py` — трей, попап (копія блоку «Надіслати» з топбару mgOS), смужка-«кишеня», інтеграція з Windows.
- Ядро — `home/.local/bin/mgos-share` з mgOS (копіюється при збірці як `mgshare_core.py`): той самий протокол, підписи HMAC, з'єднання QR.
- Дані: `%APPDATA%\MgShare` (пристрої, ключі, аватарки).

Запуск із джерел (для розробки): `pip install -r requirements.txt`, скопіювати `mgos-share` як `mgshare_core.py`, `python mgshare_win.py`.
